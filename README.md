## 📌 About

This project is a React-based admin dashboard developed as a learning project to practice frontend development, component-based architecture, and page navigation.

## ✨ Features

- 🔐 Login page
- 🧭 Sidebar navigation
- 👥 Users page
- 🏠 Home page
- ℹ️ About page
- 📱 Responsive interface
- 🌙 Dark theme

## 🛠️ Technologies

- React
- JavaScript
- CSS
- React Router
- Git and GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/MQSobhanCh/dashboard.git
cd dashboard
npm install
npm run dev
```
